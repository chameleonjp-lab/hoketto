# ホケット：画面と操作の流れ（P2・P3音設定保存）

## 初回と再訪

初回は、長い説明を読むのではなく、画面上の指示を1つずつ確認する。今回のP2では、ホームと3手順の基本説明を先に表示し、試合の時計とPhaser盤面は「遊ぶ」または説明完了・スキップを押した後に初めて開始する。説明画面を開いただけでは試合時間を消費しない。P3の音設定保存はこの画面遷移を変えず、同じブラウザで設定画面を開いた時だけ読み込む。

```text
起動 → ホーム ──「遊ぶ」→ 試合選択 → 30秒試し撃ち／90秒試合 → 結果
          │                  ↑              │          │
          └─「説明を見る」→ 基本説明1/3 → 2/3 → 3/3 ───┘
                              └─「説明を飛ばして遊ぶ」
          │
          └─「設定」→ 音と表示 ──「戻る」→ ホーム
```

追加盤面・ふつうCPUは次のP2単位で追加する。設定画面では効果音と音楽を別々に切り替える。初期状態は両方オフとし、チェックした操作からWeb Audioの処理を遅延開始する。音声を利用できないブラウザでは状態説明を出すが、試合と設定の操作は継続できる。保存領域が使える場合は設定変更時に同じブラウザへ保存し、次回に復元する。値の破損・保存領域の利用不可・容量超過は無音へ戻して一度だけ知らせ、試合を止めない。試合選択では、現在開始できるストレート・ベンチとれんしゅうに加え、「30秒の試し撃ち」または「90秒試合」を選べる。未実装の条件は解放しない。試合終了時はPhaser盤面を破棄し、HTMLの結果画面へ移る。結果画面では勝敗、得点、盤面名、CPUの強さ、遊び方を示し、「もう一度」と「ホームへ」を分ける。結果画面へ切り替わった直後の300ミリ秒はボタンを無効にし、終了時の指がそのまま再戦へ渡らないようにする。再戦は結果と同じ条件で乱数種だけを1つ進め、ホームへ戻る場合は試合を破棄して次回の時計を0秒から開始する。

## 375×667の画面案

| 画面     | 上から順に置くもの                                    | 主ボタン                   |
| -------- | ----------------------------------------------------- | -------------------------- |
| ホーム   | ロゴ、短い説明、遊べる範囲                            | 「遊ぶ」                   |
| 設定     | 効果音・音楽の個別切替、音声対応状態                  | 「戻る」                   |
| 基本説明 | 手順番号、照準・指を離す・待機確認、1文の説明、操作図 | 「次へ」／「条件を選ぶ」   |
| 試合選択 | 盤面の縮小図、解放条件、CPUの強さ、遊び方             | 「この条件で始める」       |
| 試合     | 相手得点・時間・自分得点、両砲台の状態、盤面、停止    | 盤面のPointer操作          |
| 中断     | 理由、現在の試合を保持する説明                        | 「再開」                   |
| 結果     | 勝敗、得点、盤面・試合種、最後の軌道                  | 「もう一度」／「ホームへ」 |

試合中の得点欄は、`相手［角印］ 2 ｜ 00:42 ｜ 自分［丸印］ 1` のように文字、形、色を併用する。数字だけを左右へ置いて上下の陣営を推測させない。

## 設定と音の受入範囲

ホームの「設定」から「音と表示」を開き、効果音と音楽を別々に変更できる。初回起動時は両方オフで、保存領域が使える場合は次回の同じブラウザでも設定を復元する。保存値が壊れている、使えない、容量超過した場合は無音へ戻し、その理由を一度だけ表示する。効果音を有効にすると発射と得点に短い合成音を鳴らし、音楽を有効にすると試合中だけ小さな背景音を鳴らす。どちらも無効にした時は新しい音声ノードを作らない。Web Audioが利用できない場合は説明文を表示し、音なしで全画面を操作できる。

## Pointer操作

| 状態      | 操作                                                    | 画面の反応                                | 結果                 |
| --------- | ------------------------------------------------------- | ----------------------------------------- | -------------------- |
| 発射可能  | 有効領域で指を置く                                      | 砲口から方向線と照準輪を出す              | 狙い中               |
| 狙い中    | 指を動かす                                              | 方向線を更新する                          | 狙い中               |
| 狙い中    | 有効領域で指を離す                                      | 弾と短い発射表示を出す                    | 充電中               |
| 狙い中    | 盤面外・端24px帯・`pointercancel`・`lostpointercapture` | 照準を消す                                | 取消、弾0、充電消費0 |
| 充電中    | 盤面へ触れる                                            | 充電輪を1回だけ脈動、「充電中」を短く表示 | 予約なし             |
| 2本目以降 | 指を置く                                                | 反応しない                                | 1本目を維持          |

発射可能かどうかは `pointerdown` の時点で固定する。得点、時間切れ、延長、中断、画面矩形の変更が狙い中に起きたら取り消し、後の指離しで発射しない。

試合中は、色だけに頼らず、両砲台の下へ `撃てる`、`観測中`、`充電中`、`停止` の短い文字を表示する。CPUの `観測中` は最初の反応待ち、`充電中` は次の発射までの待ち時間を表す。試合結果はHTMLで表示し、結果前の状態を再戦処理が変更してはいけない。

## P2ホーム・基本説明・試合選択の受入範囲

ホームの「遊ぶ」は試合選択へ進む。ホームの「説明を見る」は1/3、2/3、3/3を順に表示し、最後の手順または「説明を飛ばして遊ぶ」から試合選択へ進む。試合選択では、ストレート・ベンチとれんしゅう、30秒の試し撃ちまたは90秒試合が開始可能である。ツイン・ブロック、リフレクト・レーン、ふつうは解放理由を表示して押せない。開始可能な条件を選んだ時だけ「この条件で始める」が有効になる。

基本説明1/3では、白いパックを1回タップするまで「次へ」を無効にする。タップすると「照準できました」と表示し、次へ進める。これは実際の試合を開始せず、試合時計、CPU、発射待ちを消費しない操作確認である。「説明を飛ばして遊ぶ」はこの確認を省略できる。

基本説明2/3では、白いパックの操作図を押している間は完了にせず、指を離した時だけ「発射できました」と表示して次へ進める。`pointercancel` が起きた場合は押し始めた状態を取り消し、後から遅れて完了させない。キーボード操作では、ボタンのEnterまたはSpaceを1回の押して離す操作として扱う。

基本説明3/3では、2/3の操作確認後に説明専用の充電輪を900ミリ秒だけ表示する。輪が満ちるまでは「次へ」を無効にし、満ちた時だけ「待てました」と表示して進める。これは試合時計、CPU、実際の発射待ちを開始せず、`prefers-reduced-motion` の利用者にも同じ待機条件を適用する。

どの経路でも、試合画面を表示してからPhaserを生成するため、ホーム、説明、試合選択中にCPUの反応待ち・発射待ち・90秒時計は進まない。保存された音設定は画面を開いた時に読み込むが、音楽は試合画面へ入るまで開始しない。

試合から「ホームへ」を選ぶと、盤面を破棄してホームへ戻る。戻った後に再び試合へ入る時は新しい試合状態を作り、前回の弾、パック、得点、時計を持ち越さない。ブラウザの再読み込みでもホームから始める。これは保存機能ではなく、P2の明示的な状態境界である。

結果画面の「もう一度」は、結果に記録された盤面、CPUの強さ、遊び方をそのまま使い、結果の試合種に1を足した乱数で新しい試合を作る。「ホームへ」は結果を消してホームへ戻る。結果通知が遅れて到着した場合に備え、すでにホームや別の試合へ移っていれば、古い結果を現在の画面へ適用しない。音設定の保存失敗は試合の状態や勝敗へ影響させない。

## キーボード操作

盤面をTabで選び、矢印キーで照準印を8論理ピクセルずつ動かす。Shiftと矢印で1論理ピクセルずつ動かす。EnterまたはSpaceで発射し、Escapeで停止する。キーを押し続けた時の自動反復は発射へ使わず、1回の新しいキー入力につき最大1発とする。

## 中断と横向き

手動停止、画面非表示、横向き、描画領域の消失では、時計・物理・充電を止めて不透明な中断面を出す。縦向きへ戻って「再開」を押すまで自動で再開しない。初期版は横向きの試合盤面を作らず、既知の制限として記録する。
