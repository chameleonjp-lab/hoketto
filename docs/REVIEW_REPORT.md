# ホケット：独立レビュー記録（P2・P3盤面・端末内保存）

## P2ホーム・照準と指を離す確認付き基本説明・試合選択・30秒試し撃ち・ストレート・ベンチ・音設定レビュー状態

`保留`。自動検査は実装担当側で通過したが、独立確認はまだ行っていない。この文書は、実装担当の自己確認と公開前の独立確認を分けるために使う。P2の変更差分、計画書、検査結果、画面導線を新しい読み込み状態で確認し、通過・不通過・保留のいずれかを記録する。

## 確認範囲

- P0.2の画面案、規則、物理の基礎がP1試作と矛盾しないか
- 起動時にホームが表示され、「遊ぶ」「説明を見る」「説明を飛ばして遊ぶ」が意図どおり分岐するか
- 試合選択で、3盤面＋れんしゅう／ふつうが開始可能で、盤面固有の説明が表示されるか
- 試合選択で、30秒の試し撃ちと90秒試合が選べ、選んだ時間が試合と結果へ引き継がれるか
- ホームの設定から、効果音と音楽を別々に切り替えられ、初期状態が無音になっているか
- 同じブラウザを再読み込みした後も、効果音と音楽の設定が個別に復元されるか
- 保存領域が使えない、値が壊れている、容量超過した場合に無音へ戻り、ゲームを止めないか
- 試合結果が個人情報なしで同じブラウザへ保存され、最大20件を超えて古い記録が残らないか
- 結果画面のコピーが成功し、Clipboard非対応時は本文を手動選択できるか
- 基本説明を最後まで完了した後、同じブラウザの再訪で「説明をもう一度」と表示されるか
- 説明を飛ばした場合、完了状態を保存しないか
- ストレート・ベンチの「ふつう」CPUが、れんしゅうと同じ物理規則で反応時間と先読みだけを変えるか
- 効果音が発射・得点へ、音楽が試合中の背景へだけ反応し、音声非対応でもゲームを継続できるか
- 基本説明1/3で白いパックを1回タップするまで次へ進めず、完了後だけ次へ進めるか
- 基本説明2/3で押している間は完了せず、指を離した時だけ完了し、`pointercancel` で取り消されるか
- 基本説明3/3で充電輪が900ミリ秒表示され、満ちるまで次へ進めず、試合時計を開始しないか
- UIを経由しない状態関数の呼び出しでも、未実装条件を`GAME`へ進めないか
- ホームと基本説明中にPhaser、CPU反応待ち、90秒時計が開始されず、試合へ入った時だけ生成されるか
- 基本説明が3手順を順番に表示し、最後の手順から試合へ移り、試合からホームへ戻ると状態を破棄するか
- 試合終了後に盤面内のタップ再戦ではなく、勝敗・得点・再戦・ホーム戻りを持つHTML結果画面へ移るか
- 結果画面のボタンが300ミリ秒待機後に有効になり、遅れて届いた古い結果が現在の画面へ戻らないか
- 弾・パック・上下ゴール・得点・90秒時計が同じ固定更新で動くか
- CPUがプレイヤー入力を読まず、同じ弾速・待ち時間・命中判定で自動射撃するか
- 両砲台の「撃てる」「観測中」「充電中」「停止」が、色だけに頼らず読めるか
- 結果からの再戦が同じ盤面で新しい種を使い、結果前の状態を変更しないか
- 発射待ち中の入力が予約されず、結果後のタップが次の試合へ明示的に切り替わるか
- 盤面検査が不正なゴール、重なり、コア候補を拒否するか
- 線分と軸に平行な長方形の連続衝突が、角を含めて有限な値を返すか
- 10,000件の性質試験が、衝突時刻と接触距離を検査しているか
- 中断後の3秒再開、復元失敗の `INVALID`、Pointer取消が仕様と一致するか
- `INVALID` を正常な勝敗へ混ぜる実装がないか
- 未確認の手動項目を「通過」と書いていないか
- GitHub Pagesの基準パスと本番出力が一致するか
