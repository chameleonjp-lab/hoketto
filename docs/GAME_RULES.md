# ホケット：ゲーム規則（P0・P4 UX改善）

この文書は、P0で実装する「勝敗を決める規則」の最小版です。見た目や音の演出は、ここに書いた結果を変えません。

## 盤面と陣営

- 論理盤面は360×640です。上側がCPU、下側がプレイヤーです。
- 上側のゴールへパック全体が入るとプレイヤーに得点し、下側へ入るとCPUに得点します。
- ゴールの開口部の外では、外周または支柱へ先に衝突します。開口部では、パック全体が得点面を越えた時だけ得点します。
- 初期公開では円、有限の線分、軸に平行な長方形だけを物理形状に使います。回転長方形や任意多角形は扱いません。
- ストレート・ベンチは障害物なし、ツイン・ブロックは中央左右に180度回転対称の長方形ブロックを置きます。弾はブロックで消え、パックは衝突面で反射します。
- リフレクト・レーンは180度回転対称の斜め反射板を2枚置きます。弾は反射板で1回だけ反射し、2回目の接触や他の障害物では消えます。パックは反射板の面で反射します。

## 時間と得点

- 自分は下側の砲台から弾を撃ち、白いパックを上側の相手ゴールへ入れて得点します。弾を撃った後は充電が戻るまで待ちます。
- 通常試合は90秒、固定更新は1秒あたり120回です。
- 「30秒の試し撃ち」は、ストレート・ベンチ、れんしゅうCPU、得点、発射待ち、同点延長を通常試合と同じ規則で使い、試合時間だけを30秒にします。結果画面からの再戦も30秒を保ちます。
- 通常パックは1点です。高出力コアは見た目に数字「2」を置き、2点です。
- 射撃後の待ち時間の開始値は900ミリ秒です。待ち時間中に始めた操作は予約せず、弾も充電も消費しません。
- 同じ固定更新内に複数の得点が起きたら、全件を加算してから時間切れと勝敗を判定します。
- 通常時間が同点なら、ゴールを20%広げた15秒延長へ入り、先に1点を取った側が勝ちます。延長終了時に得点がなければ引き分けです。

## 画面上の意味（P4 UX改善）

- 試合盤面の背景は黒とし、白いパック、青緑の自分の弾、赤い相手の弾、赤い相手ゴールを明るく表示します。色だけでなく、弾の形と「相手ゴール」「自分ゴール」の文字も併用します。
- 試合画面のCanvas外に、白いパックを上の赤い相手ゴールへ入れる3手順と、得点が多い方が勝つことを常に表示します。
- プレイヤーの発射状態は、「撃てます」「充電中」「停止中」の文字、状態記号、進捗ゲージ、充電中の残り時間で示します。1回撃った後はゲージが満ちるまで次の弾を予約しません。
- スマホ案内は「盤面を指で押したまま方向を決め、指を離して発射」、PC案内は「マウスの押し離し」または「盤面をクリックしてから矢印・Enter／Space」とし、同じ射撃規則へ接続します。

## CPUの強さ

- れんしゅうCPUは、最初の判断まで約480ミリ秒待ち、現在のパック位置を中心に狙います。
- ふつうCPUは、最初の判断まで約280ミリ秒待ち、約180ミリ秒先のパック位置を予測して狙います。照準には毎回決まった小さな誤差を入れます。
- どちらもプレイヤーと同じ弾速、弾の寿命、射撃待ち、命中判定を使います。プレイヤーの入力を読んだり、勝敗を隠れて補正したりしません。

## キーボードと停止（P3実装済み）

- 試合盤面のCanvasはTabでフォーカスでき、フォーカス中は十字形の狙い印を表示します。矢印キーは8論理ピクセル、Shift＋矢印は1論理ピクセルずつ動かします。
- 狙い印は、盤面の安全な入力範囲内かつプレイヤー砲台より32論理ピクセル以上前方に制限します。範囲端で止まり、座標を反対側へ丸めません。
- EnterまたはSpaceを新しく押した時だけ、現在の狙いへ1発を出します。キーリピート、充電中の操作、盤面外の操作は後から発射されません。
- Escapeまたは画面の「一時停止」で `SUSPENDED` へ移り、時計、物理、充電、CPU判断を止めます。「再開」またはEnter／Spaceの明示操作後に3秒数え、停止前の試合へ戻します。結果・不正終了後は停止や再開を受け付けません。

## システム中断と復帰（P4実装済み）

- `visibilitychange`、bfcacheへ入る `pagehide`、`pageshow`、向き変更、表示領域の実寸変更、WebGL描画コンテキストの消失・復元を監視します。
- 画面が非表示、横向き、表示領域が一時的に無効、または描画コンテキストが失われた時は、理由を `hidden`、`orientation`、`resize`、`render-loss`、`lag` のいずれかで記録して `SUSPENDED` へ移します。時計、物理、充電、CPU判断、狙い中のPointerを止め、過ぎた時間を復帰後にまとめて進めません。
- 1描画あたりの固定更新は最大8回です。未処理が30更新以上、または未処理が2更新以下へ戻らない状態が30描画続いた場合は、理由を `lag` として中断し、残りを捨てます。復帰後に過去の時間をまとめて進めません。
- 表示中・縦向き・表示領域有効・描画復元済みの全条件がそろっても自動再開しません。「再開」または盤面へフォーカスしたEnter／Spaceの明示操作後に3秒数えます。条件が一つでも戻らなければ再開ボタンを無効にし、理由を画面上へ示します。
- 3秒の再開カウント中に再び中断した場合はカウントを破棄し、保存した復帰先を保ったまま `SUSPENDED` へ戻します。WebGL描画コンテキストが5秒以内に復元しない場合は勝敗を記録せず `INVALID` とし、「ホームへ戻ってやり直してください」と案内します。

## 高出力コア（P3実装済み）

- 各盤面に、中央横列の候補位置を3か所以上用意します。候補は静止形状と重ならず、180度回転対称です。
- 残り17秒で、通常パックと重ならない候補を試合の乱数から一つ選び、2秒間の予約リングを表示します。
- 予約リングはパックだけを跳ね返し、弾は通り抜けます。予告中に得点しても位置は変えません。
- 残り15秒で同じ位置のリングをコアへ置き換えます。置換時に弾が重なっている場合は、次の固定更新の時刻0で衝突させます。
- 延長へ入る時はリングとコアを消し、通常パック1個へ戻します。

## 無得点への対応（P3実装済み）

- 無得点が11秒続くと、両側へ「1秒後にゴール拡大」と予告します。
- 12秒で両ゴールを通常幅の12%だけ広げます。どちらかが得点すると、通常幅と無得点カウンタへ戻します。延長の20%拡大とは重ねません。
- 無得点が20秒続くと、全パックへ盤面中央向きの速度差分160/秒を1回加えます。中央から1論理ピクセル以内では、物体番号で決まる左右方向を使います。以後は10秒ごとに繰り返します。
- 中央波とゴール拡大は両者へ同じ条件で適用し、勝敗を隠れて補正しません。延長へ入る時は通常状態へ戻します。

## 状態と異常

試合は `COUNTDOWN`、`PLAYING`、`GOAL_PAUSE`、`OVERTIME_NOTICE`、`OVERTIME`、`RESULT`、`SUSPENDED`、`INVALID` のいずれかです。有限でない物理値、衝突処理の上限超過、復元不能な状態を見つけたら、勝敗と自己記録を保存せず `INVALID` で終了します。
