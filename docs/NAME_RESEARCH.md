# 『ホケット』名称の予備調査

## 結論

この記録だけでは、名称やロゴを安全に使えるとは判断しない。『ホケット』はP0では仮称として扱い、公開用のロゴや配布物を確定する前に、公式の商標情報を人が確認する。

## 次に人が確認すること

1. [J-PlatPat](https://www.j-platpat.inpit.go.jp/)で「ホケット」「HOKETTO」「ほけっと」を完全一致と類似検索する。
2. ゲーム、ダウンロードソフト、オンラインゲーム、娯楽サービスに関係する区分を確認する。
3. App Store、Google Play、Steam、Web検索で同名・似た名前の作品を再確認する。
4. 結果の日時、検索語、対象区分、該当件数、気になった権利者をこの表へ追記する。

商標登録の有無は、検索結果だけで法的な安全を保証しない。判断が必要な場合は専門家へ相談し、ユーザーが最終決定を行う。
