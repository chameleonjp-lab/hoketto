## 確認結果

- 720試合すべてが `RESULT` まで到達し、`invalid=0`、tick上限到達0件、得点停止後のREADY違反0件、3個を超える同時パック0件だった。
- 720試合すべてで2点コアが有効化され、コア候補0・1・2が各条件で観測された。候補選択は試合種から決まり、配列順へ依存しない。
- CPUの照準誤差の観測最大値は、ふつう5度、れんしゅう10度。診断記録にはCPUの防御／攻撃判断数も含め、同じ種と状態から同じ判断を再現できる。
- ふつうCPUの中央固定・追尾は、この固定入力ではプレイヤー15/30、16/30勝だった。盤面別の差は残るため、標準CPUの公平感と初見の勝率は実機試遊で別途確認する。
- れんしゅうCPUの中央固定は12〜18勝の範囲に入る盤面があり、これは計画書の30試合受入条件に近い診断値である。参加者の勝率を代替しない。

## 再現方法

全条件は次で再実行する。

```sh
npm run audit:gameplay
```

短縮時は `HOKETTO_GAMEPLAY_SEEDS`、`HOKETTO_GAMEPLAY_TICKS`、`HOKETTO_GAMEPLAY_BOARDS`、`HOKETTO_GAMEPLAY_DIFFICULTIES`、`HOKETTO_GAMEPLAY_MODES` を指定できる。短縮してtick上限へ達した場合は、監査失敗として終了する。
