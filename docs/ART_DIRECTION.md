# ホケット：ビジュアル方針（P0・P4）

## 目指す見え方

真夜中の町工場で、廃材から組み上げた小さな電磁スポーツ盤が動き出す。背景は暗く、試合の物体は明るくする。人物や既存作品の意匠は使わず、競技盤・銅線・磁石・表示灯を独自に描く。

## 色と意味

色だけに意味を持たせず、必ず形と文字を添える。最終的な明度差は、合成後の画面で測る。

| 役割       | 色        | 形・文字                                   |
| ---------- | --------- | ------------------------------------------ |
| ページ背景 | `#0B1020` | 暗い作業台                                 |
| 盤面       | `#000000` | 黒い競技面と明るい外周                     |
| 文字       | `#F6F8FF` | HTML文字、画像へ焼き込まない               |
| 補助文字   | `#C8D1E5` | HTML文字、4.5対1を下回る場面では下地を置く |
| プレイヤー | `#35D6C2` | 円、連続線、丸い砲台                       |
| CPU        | `#FF7A59` | 角、二重線、角形砲台                       |
| 2点コア    | `#FFD166` | 六角形と数字「2」、実際の当たり判定は円    |
| 注意・取消 | `#FF5D73` | 枠と「×」または短い文字                    |

文字は通常4.5対1、大きい文字は3対1、判断に必要な輪郭と状態表示は3対1以上を目標にする。 盤面は黒を基準にし、充電状態は色だけでなく文字、状態記号、進捗ゲージの3つで示す。P0で自動測定方法を決め、P2で発光や粒が重なった状態も確認する。

## 形と描画順

描画順は、背景、装飾、壁・反射板、軌跡・粒、パック・弾、砲台・充電輪、得点・時間・説明の順にする。パックと弾は粒より前に置き、背景のねじや傷を輪郭と似た線にしない。

- 通常パックは円と小さな横線。
- 2点コアは六角形、数字「2」、円形の細い当たり輪。
- プレイヤーの弾は丸い先端と連続した青緑の軌跡。
- CPUの弾は角形の先端と二重の赤橙の軌跡。
- 発射可能は閉じた充電輪と開いた砲口、充電中は満ちる輪と閉じた砲口で示す。
- 反射板は衝突する辺を実線で描き、発光だけで形を説明しない。
- 無得点11秒の予告は短い文「ゴール拡大予告：あと1秒」と両ゴールの輪郭で示す。12秒以降は両ゴールの開口と支柱を同じ比率で広げる。
- 中央波は中央から広がる琥珀色の細い輪を0.35秒だけ描き、同時に「中央パルス」と表示する。パックを隠す粒や強い画面点滅にはしない。

## 動きの上限

通常の粒は1イベント32個、命中輪は400ミリ秒、得点の強い点滅は使わない。画面揺れと強い残像は「動きを抑える」設定で止めるが、当たり判定と試合速度は変えない。1秒に3回を超える点滅を使わない。

## 素材の納品規則

パック、弾、充電輪、方向線、命中輪、簡単な反射板はCanvasの図形で描き、解像度に依存しないようにする。画像を追加する場合は、元データ、書き出し形式、寸法、基準点、当たり範囲、権利元を記録する。ロゴ以外の文字は画像へ焼き込まない。
