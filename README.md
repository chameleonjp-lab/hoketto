# ホケット

『ホケット』は、固定された発射装置から弾を撃ち、パックへ当てて相手ゴールを狙う縦画面のブラウザゲームです。

現在はP2の基本導線試作段階です。起動時のホーム、3手順の基本説明、試合選択、説明を飛ばして遊ぶ導線、縦画面のCanvas描画、固定更新の物理、Pointer入力、弾・パック・ゴール・得点・90秒時計、同じ物理規則で動くCPUの自動射撃、両砲台の発射状態表示、HTMLの結果画面、同条件再戦を実装しています。ふつうCPU、複数盤面、30秒練習、音は次の工程です。
