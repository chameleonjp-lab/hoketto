# ホケット

『ホケット』は、固定された発射装置から弾を撃ち、パックへ当てて相手ゴールを狙う縦画面のブラウザゲームです。

## どんなゲーム？

1人でCPUと対戦する、ホッケーと射撃を組み合わせたゲームです。自分の装置は盤面の下に固定されていて、移動する代わりに弾を白いパックへ当てます。パックを上の相手ゴールへ押し込み、90秒の試合で得点を競います。

## 遊び方

1. ホームの基本説明で「狙う・離して撃つ・充電を待つ」を試します。説明から射撃場へ進むことも、説明を飛ばすこともできます。
2. 試合選択で盤面と難易度を選び、CPU戦を始めます。盤面はストレート・ベンチ、ツイン・ブロック、リフレクト・レーンの3種類です。
3. スマホは盤面を押したまま狙い、指を離すと1発撃ちます。PCはマウスの押下・移動・解放、または盤面をクリックしてから矢印キーで照準、Enter／Spaceで発射します。
4. 1発撃つと次の充電を待ちます。パックの動きや壁の反射を読み、ゴールへ入る角度を狙ってください。

通常のパックは1点、終盤に現れるコアは2点です。90秒終了時に同点なら延長戦に入り、先に得点した側が勝ちます。延長終了まで得点がなければ引き分けです。

音楽と効果音は別々に設定できます。画面を離れたり端末の向きが変わったりして中断した場合は、元の状態に戻して「再開」を押します。

名前を入力して開始し、終了時には名前とスコアをオンラインランキングへ送信する実装です。通信に失敗しても保存済みの試合結果は確認できます。盤面・難易度を混ぜたランキングの公平性は未検証です。ここでは送信処理の実装を確認しており、今回の文書更新で本番送信試験はしていません。

## 開発者向け

Node.js 24以上を使用します。

```sh
npm ci
npm run dev
```

起動時に表示されるローカルURLを開いてください。公開用ビルドは `npm run build`、自動試験は `npm test` です。
