# ホケット

『ホケット』は、固定された発射装置から弾を撃ち、パックへ当てて相手ゴールを狙う縦画面のブラウザゲームです。

現在はP4先行のシステム中断・遅延監視と、H13の実物理射撃場、H14の発射・命中・反射・得点フィードバック、H10〜H12の得点後再開・CPU判断・ゲームプレイ監査まで進んだ段階です。ホーム、試合選択、最大化したゲーム、結果の4画面を用意し、通常の対戦は90秒に統一しています。照準・指を離す・待機を試せる基本説明、説明から開く射撃場、完了状態の復元、説明を飛ばして遊ぶ導線、効果音・音楽の個別設定、試合結果の保存とコピー、保存不可・破損時の復旧、縦画面のCanvas描画、固定更新の物理、Pointer／キーボード入力、停止・3秒再開、画面非表示・bfcache・横向き・表示領域変更・WebGL復元時のシステム中断、弾・パック・障害物・反射板・予約リング・盤面内ランダム2点コア・ゴール拡大・中央波・得点・90秒時計、弾とパックの軌跡・命中輪・反射火花・ゴール輪、プレイヤー弾の外周壁1回反射、直線に偏らないCPUのスイープ照準、充電量に応じた黒→白の盤面色と満タン時の白フラッシュ／コア色を実装しています。ストレート・ベンチ、ツイン・ブロック、リフレクト・レーンを開始できます。音声や保存領域が利用できない場合もゲームを継続できます。

## 公開

公開先URLは [https://chameleonjp-lab.github.io/hoketto/](https://chameleonjp-lab.github.io/hoketto/) です。GitHub Pagesは、`main`へのマージ後にGitHub Actionsの「Deploy GitHub Pages」がビルドした`dist`を公開します。初回だけ、リポジトリのSettings → Pages → Build and deployment → Sourceで「GitHub Actions」を選びます。
