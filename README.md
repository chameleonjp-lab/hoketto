# ホケット

『ホケット』は、固定された発射装置から弾を撃ち、パックへ当てて相手ゴールを狙う縦画面のブラウザゲームです。

現在はP0.2の技術試作段階です。縦画面のCanvas描画、盤面規則、衝突計算、中断復帰、Pointer入力の自動検査を実装しています。得点付きの実戦とCPU戦はまだ実装していません。
