# ホケット

『ホケット』は、固定された発射装置から弾を撃ち、パックへ当てて相手ゴールを狙う縦画面のブラウザゲームです。

現在はP1のストレート・ベンチ試作段階です。縦画面のCanvas描画、固定更新の物理、Pointer入力、弾・パック・ゴール・得点・90秒時計、同じ物理規則で動くCPUの自動射撃を実装しています。CPUの難易度調整、複数盤面、音、正式なホーム・結果画面は次の工程です。
