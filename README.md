# ホケット

『ホケット』は、固定された発射装置から弾を撃ち、パックへ当てて相手ゴールを狙う縦画面のブラウザゲームです。

現在はP0.1の技術試作段階です。縦画面のCanvas描画、座標、盤面規則の最小検査を実装しています。得点やCPU戦はまだ実装していません。
